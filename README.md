**Lumina – AI Journaling App**

Lumina is a cross-platform journaling app designed to support Gen Z mental health. It combines AI-driven prompts, mood tracking, and an intuitive interface to help users reflect on daily experiences.

**Key Features**

Personalized AI journaling prompts
(Not all features are currently working, please refer to the demo video)

**Tech Stack**

Frontend: React Native, ExpoGo
Backend: Node.js
Database: SQL

AI Integration: Python scripts, OpenAI API

Tools: Git, Figma
